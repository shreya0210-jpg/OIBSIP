# Data Science Internship - Task 1: Iris Flower Classification

This repository contains the completed **Task 1: Iris Flower Classification** project as part of the Oasis Infobyte Data Science Internship (`OIBSIP`).

## Project Objective
The goal of this project is to build a machine learning model that can predict the specific species of an iris flower based on its physical measurements: sepal length, sepal width, petal length, and petal width. The dataset contains three target species: *Iris setosa*, *Iris versicolor*, and *Iris virginica*.
