# Oasis Infobyte Data Science Internship (OIBSIP)

This repository contains the Machine Learning projects completed as part of the **Oasis Infobyte Data Science Internship**.

## Projects

### 🌸 Iris Flower Classification

Classifies Iris flowers into Setosa, Versicolor, and Virginica using machine learning.

### 🚗 Car Price Prediction

Predicts the selling price of used cars using regression models.

### 📧 Email Spam Detection

Classifies SMS messages as Spam or Ham using Natural Language Processing (NLP) and Machine Learning.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* NLTK
* Jupyter Notebook
