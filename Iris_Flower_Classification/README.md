# 🌸 Iris Flower Classification using Machine Learning

## 📌 Objective

The objective of this project is to classify Iris flowers into one of three species—**Setosa**, **Versicolor**, or **Virginica**—based on their sepal and petal measurements using Machine Learning.

## 📂 Dataset

* **Dataset:** Iris Flower Dataset
* **Features:**

  * Sepal Length
  * Sepal Width
  * Petal Length
  * Petal Width
* **Target Classes:**

  * Setosa
  * Versicolor
  * Virginica

## 🚀 Project Workflow

* Data Loading
* Data Exploration
* Exploratory Data Analysis (EDA)
* Data Preprocessing
* Train-Test Split
* Model Training
* Model Evaluation
* Prediction of Iris Species

## 🤖 Machine Learning Model

* K-Nearest Neighbors (KNN)

## 📊 Evaluation Metrics

* Accuracy Score
* Classification Report
* Confusion Matrix

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 📈 Results

The K-Nearest Neighbors (KNN) model successfully classified Iris flower species with high accuracy, demonstrating the effectiveness of machine learning for multiclass classification tasks.

## 📌 Conclusion

This project demonstrates how machine learning can accurately classify Iris flower species based on their physical characteristics. It serves as a beginner-friendly classification project and provides a strong foundation for understanding supervised learning techniques.
